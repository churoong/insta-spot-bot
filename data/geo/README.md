# 행정구역 경계 (국밥 국경선 지도용)

- `sigungu-2013.json`, `sido-2013.json` — 통계청(KOSTAT) 2013 시군구·시도 경계 간략판.
  출처: https://github.com/southkorea/southkorea-maps (`kostat/2013/json/*_geo_simple.json`),
  라이선스 "KOSTAT: Free to share or remix". 좌표는 소수 4자리(약 10m)로 줄였다.
- 2013 기준이라 이후 변경(2023 군위군 대구 편입, 2014 청주·청원 통합 등)은 반영되지 않았다.
  지도에서는 가게 좌표가 어느 경계 안에 있는지로 세므로 집계 자체는 틀리지 않고, 경계선 모양만 옛것이다.
